# 出处与使用

论文参考 PNG 是公开论文 PDF 的机制区域裁剪。catalog 保留论文、会议期刊、年份、图号、页码、正式来源与实际版本地址。公开获取不等于自由再发布，原作者及出版商保留权利。图像作为布局和视觉参考，生成新图应使用用户自己的机制、文字与素材。

原创结构蓝图来自本地模板库，标为 `original_blueprint`，按 MIT 许可使用。它们是通用表达结构，不是相应论文算法的精确复刻。skill 原创说明、脚本和 taxonomy 同样按 MIT；第三方论文图不包含在该许可内。

风格分类是本库人工描述，不是对会议官方标准的声明；缩略图类型与风格检查不替代完整论文内容审核。
